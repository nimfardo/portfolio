# Crawling is open on purpose. The portfolio is meant to be found — the
# public project pages, About and Process included.
User-agent: *
Allow: /

# Deliberately no `Disallow` rules, and deliberately no route names in this
# file either — it is the one file every crawler is guaranteed to read, so
# naming the gated routes here would publish exactly what they exist to keep
# private. (An earlier revision of this comment listed them. It shouldn't have.)
#
# The gated project pages carry `<meta name="robots" content="noindex">`
# instead of a Disallow, and that ordering matters: a crawler has to be able
# to FETCH a page to see that tag. Disallowing an already-indexed URL blocks
# the re-crawl, so the tag is never read and the stale entry sits in the index
# indefinitely — the opposite of the intent. See bug-073 / bug-074.
